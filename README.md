# Entre o Rio e a Bahia

Landing page interativa desenvolvida como projeto pessoal
para prática de front-end e animações.

## Tecnologias
- HTML5
- TailwindCSS (CDN)
- JavaScript (Vanilla)

## Observação
Alguns conteúdos visuais e interativos foram deixados
intencionalmente como placeholders, permitindo liberdade
criativa para futuras atualizações.
